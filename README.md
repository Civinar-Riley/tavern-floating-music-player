# 桃桃 · 余音 — 悬浮音乐播放器（二改版）

> 基于 桃mini（@wobushirenji.）的「悬浮音乐播放器」二改。
> 逐轮改动明细见 [更新记录.md](更新记录.md)。

SillyTavern（酒馆）+ 酒馆助手 全局脚本：一个不依赖消息与角色卡的独立悬浮音乐播放器。搜歌名或歌手即可播放，无需填写音频链接或 Token。

## 功能

- **搜索播放**：内置公开网易云 / QQ 音乐搜索与按需播放地址，自动尝试同曲其他音源与备用接口
- **歌词**：悬浮歌词条（胶囊形两行）+ 可展开完整歌词；支持 LRC 时间轴、翻译合并、纯文本歌词
- **歌单**：多歌单管理、我喜欢收藏、网易云歌单导入（分享文字 / 链接 / 数字 ID）
- **播放模式**：顺序 / 列表循环 / 单曲循环 / 随机（一轮内不重复，可回退上一首）
- **缓存**：整首 MP3 缓存后播放，播放时预缓存后续最多 3 首及歌词（内存上限 4 首 / 96 MB）
- **外观**：自带「夜色」暗色主题（默认）与「跟随酒馆」双主题切换；窗口可拖动、可收起，收起后继续播放；悬浮图标可换自定义图片
- **锁屏控制**：手机锁屏 / 通知栏 / 媒体键 / 蓝牙耳机显示歌名并可控制播放与进度（Media Session）
- **数据**：歌单双通道保存（脚本变量 + 浏览器 localStorage 备份），删除脚本重装可恢复；系统省流量模式下自动跳过预缓存

## 安装

1. SillyTavern 安装并启用 [酒馆助手（JS-Slash-Runner）](https://github.com/N0VI028/JS-Slash-Runner)
2. 下载 `酒馆助手脚本-悬浮音乐播放器.json`，导入酒馆助手【全局脚本库】并启用
3. 若装过旧版播放器（Swipe 版或本脚本的旧版本），刷新页面后旧实例会自动清理；旧歌单数据保留

## 使用

点击窗口右上角「−」收起为悬浮音符，点击音符展开；窗口与悬浮条都可拖动。详情见脚本导入后弹出的描述文字。

## 已知限制

- 公共音源存在可用性与曲目限制，QQ 音乐部分曲目可能仅能搜索而无法取得音频，不保证所有歌曲可播
- 音频仅缓存在当前页面内存中，刷新页面后不保留；重开不会自动出声
